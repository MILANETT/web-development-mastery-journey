# Submissions

Store your own work here, organized by challenge:

```text
submissions/
└── WDXXX/
    ├── [your source files]
    ├── assets/
    └── review.md
```

Create a folder only when you have work to submit. Follow the specific deliverables and naming rules in the relevant challenge brief.

Do not put passwords, API keys, tokens, or other secrets in submissions.
