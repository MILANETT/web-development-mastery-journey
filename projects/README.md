# Projects

This directory is for phase milestone projects and portfolio work.

A project should be added when its prerequisites have been covered. Each project should have a brief describing:
- purpose and intended users;
- problem statement and requirements;
- scope and exclusions;
- user flows, sitemap, and design deliverables where relevant;
- technical approach and constraints;
- acceptance criteria;
- testing, accessibility, and quality expectations;
- deployment and handover requirements where relevant.

The future business website for the user's mother is a real-client project and should be planned only when the necessary foundations have been demonstrated.
