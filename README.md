# Web Development Mastery Journey

A structured, mastery-led journey from web fundamentals to professional full-stack development.

## Start here

1. Read the [master roadmap](ROADMAP.md).
2. Review the [learning workflow](docs/LEARNING_WORKFLOW.md).
3. Check [progress tracking](progress/PROGRESS.md).
4. Use the templates when challenges and projects are introduced.

## Learning rules

- One weekly challenge, normally due Sunday.
- Every challenge states its current concepts and the next challenge's preparation topics.
- Submit your own work for review; make corrections after feedback.
- A cumulative boss battle is expected after approximately 4–6 regular challenges.
- Progress depends on demonstrated understanding, not simply the calendar.
- UI/UX and implementation are both part of the curriculum.
- Do not skip prerequisites just to reach a new technology.
